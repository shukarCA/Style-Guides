## VSCode Settings and Tooling

For HTML/CSS I currently have 3 extensions, one of which uses an npm tool.

Stylelint, and it's terminal tools, handle linting and enforcing style rules.
CSSComb, from mrmlnc, enforces alphabetical property order, and whitespace.
HTML CSS Support, from ecmel, is there mainly for when I do actual HTML work.
